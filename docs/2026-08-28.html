LLM의 신뢰성 한계를 에이전트 강화학습과 실행 검증으로 보완하는 중

LLM 자체의 확률 신념이 내부적으로 불일관하다는 것이 정량화되면서(1번), 확률 기반 모델의 근본적 한계가 드러났다. 이에 따라 LLM을 '생각하는 시스템'이 아니라 '행동하는 시스템'(에이전트)으로 전환하되, 강화학습을 통해 GUI 조작이나 SQL 생성 같은 구체적 작업에서 성능을 높이고(13, 14번), 동시에 런타임 경보(15번)와 현실 작업 환경에서의 평가(16번)로 신뢰성을 보장하는 방향으로 이동 중이다.
