# Codex CLI 호출 전환

- 공통 호출을 `_run_codex`로 바꾸고 요약·번역·선별·해석·SVG 호출과 테스트를 함께 변경한다.
- `codex exec`에 stdin으로 프롬프트를 전달하고, `--output-last-message`의 최종 응답만 읽는다. 임시 디렉터리는 호출별로 분리한다.
- 모델은 사용자 지정 `gpt-6.1-sol`을 명시한다. read-only sandbox와 ephemeral 실행을 사용하며 호출별 제한은 600초로 통일하고 배치 전체 제한은 6시간으로 늘린다. 실패 시 빈 문자열 계약을 유지한다.
- CLI 미설치, 비정상 종료, 타임아웃, 응답 파일 오류를 검증한다. 기존 전체 테스트를 실행한다.
- npm 실행기가 네이티브 Codex 자식을 남기는 문제를 막기 위해 호출별 프로세스 그룹을 만들고, 타임아웃이나 배치 중단 시 그룹 전체를 종료한 뒤 회수한다. 실제 실행기·자식 프로세스의 heartbeat 중단과 SystemExit 전파로 회귀 검증한다.
- launchd/Orca 예약, 프롬프트 내용, 발행 흐름은 변경 범위에 포함하지 않는다.

## 복구 중 확인된 원문 입력 문제

GitHub README의 HTML 배지와 Markdown 이미지·링크 주소가 앞부분을 채워 본문이 잘리는 사례를 확인했다. 기존 BeautifulSoup로 HTML 텍스트를 추출하고 Markdown 이미지와 링크 주소를 정리한 뒤 길이를 제한한다. 긴 배지 뒤 본문이 분석 입력에 남는 회귀 테스트를 추가한다.
