Mixture-of-Loops Transformer
arXiv
KV 메모리를 깊이와 루프에 걸쳐 선택적으로 재사용해 표현력과 효율을 높이는 Mixture-of-Loops Transformer(MoLT)를 제안한 연구.
- MoLA는 키·값(KV)을 메모리로 활용한다. MoLT-R은 잔차 스트림을 유지하고 루프 간 로컬 KV를 읽으며, MoLT-KV는 임베딩에서 다시 시작해 현재 루프의 로컬 KV와 이전 루프의 앞선 위치에 있는 메모리 KV를 읽는다.
- MoLT-KV는 같은 위치의 루프 간 의존성을 제거하고, 병렬 학습을 위한 loop forcing과 결합해 학습한 루프 범위를 넘어서는 단일 순회 MoL 디코딩을 가능하게 한다. U-MoLT는 메모리 구성과 예측 출력을 분리해 예측 결과를 바꾸지 않고 불필요한 디코더 순회를 생략한다.
- 4,000억 토큰 사전학습에서 U-MoLT는 700M·1.5B 밀집 모델과 3B MoE 모델에서 OLMo3를 능가했다. 700M에서 검증 교차엔트로피 기준 토큰 효율이 1.7배였으며, 3B MoE에서 10개 도메인 perplexity는 0.75 낮아지고 10개 과제 정확도는 2.1%포인트 높아졌다.

- 간소화된 2조항 BSD 유사 라이선스로 배포되는 무료 오픈소스 소프트웨어이며, F5가 기업용 배포판·상용 지원·교육을 제공한다.
- README는 초보자를 위한 기본 안내이며, 설치·빌드·설정·디버깅과 모듈·지시어의 상세 정보는 전체 NGINX 문서를 참조하도록 안내한다.
