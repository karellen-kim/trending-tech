Concertina: 하나의 Diffusion Vision-Language Model에 조작과 인지 통합하기
arXiv
Concertina는 연속적인 로봇 조작 궤적 생성과 인지를 하나의 diffusion VLM 백본에 통합한 Embodied Vision-Language Model(eVLM)이다.
- 각 제어 시점을 백본 은닉 공간의 연속 잠재 행동 토큰 하나로 인코딩하고, 공유 Transformer가 멀티모달 사전학습과 동일한 손상·복원 연산으로 시간순 행동 블록을 복원한다. 물리 좌표 기반 지도학습도 공유 백본의 연산·파라미터 경로에 직접 통합한다.
- 44.6억 파라미터 모델에서 활성 행동 투영은 전체 파라미터의 0.21%이며, 별도의 행동 생성 계층은 없다. 비교 대상으로 제시된 연속형 VLA의 전용 행동 전문가 비중은 16.5~35.1%다.
- 제안한 Action Interface Audit으로 서로 다른 시점의 궤적 간 결합이 행동 인터페이스가 아니라 공유 백본의 중간·후반 계층에서 형성됨을 확인했다.
Test-Time Self-Play: 검증기 없이 성능 확장하기
arXiv
검증기에 의존하지 않고 비대칭 자기 대결로 추론 시점의 성능을 높이는 Test-Time Self-Play(TTSP)를 소개한 글이다.
- 난이도를 보정한 LiveCodeBench v6 하위 집합에서 평가한 모든 검증기 성능 수준에 걸쳐 TTSP가 가장 높은 성능을 기록했다.
- 검증기 성능이 약해질수록 가장 강력한 기준 방법과의 격차가 커졌으며, 검증기가 없는 조건에서는 mean@8이 절대 기준 35%포인트 향상됐다.
- 다양한 검증기 성능 수준에서 개선 효과가 유지됐지만, 기본 정책이 정답을 생성할 가능성이 거의 없는 경우에는 효과가 나타나지 않았다.
Recursive Sparse Attention: 로그 규모의 비용으로 백만 토큰 길이 외삽
arXiv
학습 길이를 넘어 최대 200만 토큰까지 처리하는 희소 어텐션 기법 RecSA를 제안한 글이다.
- KV 캐시를 트리로 구성하고 각 하위 트리를 하나의 키와 평균 풀링한 값으로 요약한다. 각 계층에서 최대 k개 후보를 선택해 쿼리당 선택 비용과 읽는 항목 수를 O(log L)로 줄인다.
- 각 항목의 RoPE 위치를 해당 계층 후보들 사이의 인덱스로 지정해, 문맥이 길어져도 모든 상대 거리가 학습 중 관측한 범위에 머물도록 한다.
- Qwen3-4B에서 초기화해 32K 길이로 6.2억 토큰을 학습했으며, RULER의 131K~2M 모든 평가 길이에서 기준 모델들을 앞섰다. 1M에서 60.5점으로 최상위 기준 모델인 Dense + DCA의 40.0점을 넘어섰고, 최적화 커널 적용 시 64K~2M에서 전체 프리필과 디코딩도 dense attention보다 빨랐다.
