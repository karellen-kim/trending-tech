★Agentao: 도구 사용 LLM 에이전트를 위한 관리된 로컬 우선 런타임 arXiv
도구를 사용하는 LLM 에이전트의 보안 위험을 해결하기 위한 런타임 설계
- LLM 에이전트는 도구 실행, 로컬 상태 수정, persistent memory 사용, 외부 프로토콜 상호작용을 수행
- over-privileged actions, weak auditability, prompt injection, tool poisoning, uncontrolled side effects 등의 위험 발생
- 모델 생성 action proposals와 host-authorized execution을 분리하는 layered architecture로 위험 완화
Agentao: 도구 사용 LLM 에이전트를 위한 관리된 로컬 우선 런타임 →
★Second Thought: LLM 에이전트의 행동 중 병렬 추론 arXiv
ReAct 패러다임의 LLM 에이전트 추론 효율 개선 프레임워크.
- ReAct 패러다임에서 에이전트가 action을 실행하고 environment의 응답을 기다리는 동안 추론이 정지되는 'reasoning idle window' 문제 식별
- 이 idle window를 활용하기 위해 Second Thought라는 training-free inference 프레임워크 제안
- 각 Thought phase마다 4개의 auxiliary branches를 병렬로 포크하여 미래 턴을 위한 추가 추론 수행
Second Thought: LLM 에이전트의 행동 중 병렬 추론 →
