Cloudflare WAF가 ruby2shell(CVE-2026-132825)을 차단하는 방법
Cloudflare Blog
Ruby 취약점 ruby2shell의 영향과 Cloudflare WAF의 차단 조치를 설명하는 글이다.
- 2026년 11월 19일 공개된 ruby2shell은 Ruby 문자열 대소문자 변환의 힙 버퍼 오버플로 취약점이다. 심각도는 Critical이며, 일부 상황에서 원격 코드 실행을 달성한 개념 증명이 확인됐다. 수정 버전은 Ruby 3.3.14, 3.4.13, 4.0.10이다.
- Veria Labs에 따르면 Ruby on Rails와 classic-style Sinatra 애플리케이션은 기본 설정에서 인증 전에 취약점에 도달할 수 있다. 공개 당시 GitLab, GitHub Enterprise Server, Mastodon 등의 최신 릴리스에도 영향을 받는 Ruby가 포함돼 있었다.
- Cloudflare는 Free 요금제를 포함한 모든 고객에게 ruby2shell과 관련 정수 오버플로 GHSA-87fm-7w84-j2px를 차단하는 WAF 규칙 2개를 기본 Block 동작으로 제공한다. WAF가 보지 못하는 경로로도 공격이 가능하므로 완전한 해결에는 Ruby 업그레이드가 필요하다.

Cloudflare Blog
PHP 취약점 phpAfterShell과 함께 수정된 주요 취약점에 대한 Cloudflare WAF의 대응을 설명한 글이다.
- phpAfterShell(CVE-2026-126714)은 PHP 기본 파일 기반 세션 핸들러에서 원격 코드 실행을 유발할 수 있는 취약점으로, CVSS 4.0 점수는 9.2점이다. PHP는 공개 당일인 2026년 11월 19일에 8.2.36·8.3.37·8.4.28·8.5.13·8.6.0에서 이를 수정했으며, 이 버전들은 다른 보안 취약점 16개도 수정했다.
- Cloudflare는 2026년 10월 php2shell 대응을 위해 배포한 PHP 원격 코드 실행 탐지 규칙을 11월 19일 보강해 알려진 phpAfterShell 공격 패턴을 차단한다. 이 규칙은 Free 플랜에도 제공되며 기본 활성화되고 기본 동작은 Block이다.
- 유료 플랜에는 PHP-FPM 요청 스머글링 취약점(CVE-2026-129289) 대응 규칙 1개와 SOAP 확장 취약점(CVE-2026-15353·CVE-2026-129506) 대응 규칙 2개가 추가됐다. 탐지 패턴이 정상 트래픽에도 나타날 수 있어 기본 동작은 Log다.

★예산 내재화: 고정 예산 RLVR은 테스트 시점 확장성을 예산 내 정확도와 맞바꾼다
arXiv
고정된 생성 토큰 예산으로 학습한 모델이 그 한도를 학습된 제약으로 내재화하는 현상을 분석한 글이다.
- RLVR 학습 후 모델은 학습 예산을 넘어서는 추가 토큰을 거의 사용하지 않았다. 학습 예산 근처에서는 기반 모델보다 정확도가 높았지만, 더 큰 예산에서는 정확도 향상이 멈추고 기반 모델보다 낮아졌다.
- 이 현상은 Qwen3.5-4B, Gemma4-E2B, Nemotron-3-Nano-4B의 수학 추론 및 다양한 절차적 생성 문제 학습에서 관찰됐으며, 수학 학습에서 과학·코딩 과제로도 전이됐다.
- 더 강한 KL 정규화는 확장성을 더 보존했지만 예산 내 정확도를 낮췄다. 잘린 학습 생성 결과에 답변을 강제하면 내재화와 예산 내 성능 이득이 대부분 사라졌다. 인위적으로 자른 추론 과정으로 SFT를 해도 내재화가 재현됐지만, 자연스럽게 짧은 추론 과정에서는 재현되지 않았다.
