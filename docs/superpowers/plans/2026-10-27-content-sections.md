# 수집 항목과 요약 표시 변경

- Sam Newman과 Murat Demirbas의 공식 RSS를 개발자 출처로 추가하고 AI/LLM 논문 상한을 3편으로 변경한다.
- HN과 Reddit을 분리한다. 정기 실행은 보고일 전날의 HN past 페이지(UTC 날짜)에 표시된 1~3위 순서를 그대로 사용한다. 점수 재정렬이나 과거 URL 중복 제거로 순위를 바꾸지 않는다.
- HN 수집은 날짜를 명시적으로 받는다. 이번 26일 보고서 재실행은 사용자가 지정한 2026-10-26 HN 페이지를 사용한다. 일반 실행 기본값과 복구의 명시 날짜를 구분한다.
- Reddit은 기존 수집 방식과 Reddit 전체 최대 5개를 유지하며 HN과 섞지 않는다. JSON의 hn/reddit 및 HN 기준일을 보존하고 옛 community 데이터도 표시할 수 있게 한다.
- HN/Reddit 본문이 제공되거나 읽을 수 있으면 요약한다. 본문이 없으면 제목 번역만 남기고 내용 요약을 지어내지 않는다.
- 정기 배치의 SVG/diagram 생성 호출과 옵션을 제거한다. 과거 페이지/수동 도구의 자료는 삭제하지 않는다.
- 모든 항목의 요약은 접기/펼치기 없이 바로 표시한다. 링크·메타데이터와 기존 오디오 링크는 보존한다.
- 테스트를 먼저 추가하고 실제 HN 페이지의 날짜·순서·파싱을 검증한다. 완료 후 26일자로 재실행하되 HN 일자를 26일로 지정하고 기존 일별 JSON의 Notebook URL을 재사용해 중복 생성을 피한다. 기존 노트북 내용은 유지한다.
