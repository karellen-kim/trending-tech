Cloudflare는 Workers AI와 AI Gateway를 통합해 에이전트용 제어 플레인을 구축했고, 알리바바는 Apache Fluss로 실시간 데이터 레이크를 완성시켰으며, AMD는 Taalas 인수로 모델을 실리콘에 새겼다. 플랫폼·컴퓨트·데이터 각 계층이 에이전트의 작동 방식(실시간·온라인 쿼리)에 맞춰 동시에 재설계되는 흐름이다.

핵심 문서

  2. Workers AI와 AI Gateway를 단일 AI 컨트롤 플레인으로 통합에이전트용 제어 플레인 실제 구현
  3. Apache Fluss가 톱 레벨 프로젝트로 승격, Lakestream으로 Agentic Lake 완전 실시간화 실현에이전트를 위한 실시간 데이터 인프라
  4. AMD가 Taalas 인수, 모델을 실리콘에 새겨 추론 성능 강화수직 통합의 극단, 모델→하드웨어
