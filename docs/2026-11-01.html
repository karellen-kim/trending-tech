★ 오늘의 해석

AI의 작업 공간이 대화창에서 데이터베이스·실행 화면으로 넓어지면서, 작업을 어디까지 격리할지가 보안 문제가 된다.

기본 모델 설정을 이어받는 Datasette Agent는 데이터 도구에 AI를 연결하는 절차를 줄이고, Lakebase는 에이전트가 실제 데이터를 변경하되 다른 작업과 운영 환경에 영향을 주지 않도록 작업별 DB 브랜치를 제안한다. 반대로 ChatGPT 계정 탈취 사례에서는 HTML 미리보기의 격리 경계가 뚫리자 비공개 데이터 접근과 사용자 대신 행동하는 권한까지 노출됐다. 이들을 관통하는 쟁점은 AI에 실행 공간을 제공할 때 데이터와 계정 권한의 경계도 함께 설계해야 한다는 것이다.

★CI/CD를 위한 Lakebase 브랜칭: PR 데이터베이스 100개에서 얻은 교훈
Databricks Blog
Snorkel AI가 CI/CD에서 각 PR에 독립적인 Lakebase Postgres 데이터베이스를 제공한 사례를 다룬 글이다.
- 각 열린 PR에 프로덕션 데이터의 읽기·쓰기가 가능한 복사본을 제공하며, 준비 시간을 30분 이상에서 1분 미만으로 줄였다.
- copy-on-write 방식으로 약 2.5TB의 프로덕션 데이터에 PR 데이터베이스 100개를 동시에 운영해도 각 브랜치에서 변경한 데이터만큼만 저장 공간이 추가된다.
- 브랜치 만료 시간(TTL)으로 PR이 끝난 브랜치를 자동 정리해, 저장 공간을 프로덕션 데이터와 활성 PR의 변경분을 합친 크기에 가깝게 유지한다.

★우리는 어떻게 ChatGPT 계정을 탈취했나
Simon Willison
Parameter Labs가 ChatGPT의 HTML previews에서 발견한 계정 탈취 취약점과 공격 경로를 다룬 글이다.
- MathLive 가상 키보드의 postMessage() 수신 코드가 innerHTML을 사용해, HTML preview의 샌드박스 iframe에서도 부모 페이지에 HTML을 삽입할 수 있었다.
- 공격자는 삽입한 HTML로 샌드박스 제한이 없는 새 iframe을 만들고, CSP가 허용한 YouTube 도메인의 oEmbed 엔드포인트를 이용해 JavaScript를 실행했다.
- ChatGPT에서 JavaScript를 실행할 수 있게 되자 API를 통해 사용자의 비공개 데이터를 가져와 외부로 유출할 수 있었다.
★datasette-llm 0.1a9
Simon Willison
datasette-llm 0.1a9에서 Datasette Agent의 기본 모델 설정을 간소화한 업데이트를 소개한다.
- 2026년 10월 31일 공개된 버전으로, 다른 플러그인이 의존해 사용할 수 있는 LLM 통합 플러그인이다.

TCP 해제 후 사용 취약점: CVE-2026-98432 / CVSS 9.8
3위 · 728 pts
Linux의 IPv4 TCP 핸드셰이크 취약점과 배포판별 커널 패치 현황을 다룬 글이다.
- CVE-2026-98432는 Linux 4.4부터 존재하는 해제 후 사용 취약점으로, 인증되지 않은 원격 공격자가 접근할 수 있으며 CVSS 3.1 점수는 9.8점이다.
- Linux 안정 커널은 2026년 10월 11일과 15일에 수정됐고, Red Hat은 11월 1일 RHEL 8·9·10용 패치 커널을 배포했다. 같은 날 기준 Ubuntu는 패치가 없고 AlmaLinux는 테스트 중이다.
- multipath TCP를 꺼도 해결되지 않는다. Anthropic의 root 권한 획득 공격에는 MPTCP 리스너가 필요했지만, 버그 자체는 일반 IPv4 TCP에 있으며 Go Security Team은 MPTCP 리스너가 없는 시스템도 유사한 공격에 취약할 가능성이 있다고 밝혔다.
