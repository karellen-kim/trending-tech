Spotify Engineering
Spotify 등의 기업은 온라인 서비스와 AI 에이전트용으로 사용자 데이터에 대한 빠른 포인트 쿼리가 필요하지만, GCS 데이터 레이크의 exabytes 규모 데이터 접근 시 Trino, BigQuery 같은 분산 SQL 엔진은 단일 행 조회에도 초 단위 오버헤드를 추가합니다. Random Access Parquet(RAP)는 외부 인덱스로 키를 파일 위치에 직접 매핑하고 필요한 바이트만 정확히 읽어 이 문제를 해결합니다. RAP는 기존 Parquet 파일에서 작동하므로 별도 저장 시스템 유지 비용이 없습니다.

firecrawl/pdf-inspector
9,496
pdf-inspector는 Firecrawl의 Rust 라이브러리로, OCR 없이 PDF를 분류하고 텍스트를 추출하며 마크다운으로 변환한다. 스마트 분류, 테이블 감지, 다중 컬럼 레이아웃 인식, CID 폰트 지원 등의 기능을 제공한다. Python, Node.js, 브라우저 WebAssembly 바인딩을 포함하며, 약 200ms 이내에 텍스트 기반 PDF를 처리해 OCR 비용을 절감할 수 있다.

uber/ADR
574
ADR(Agentic AI Detection and Response)은 Cursor, Claude Code, Codex 같은 직원 대면 AI 에이전트와 고객 지원 에이전트를 보호하는 엔터프라이즈 보안 시스템으로, Uber에서 프로덕션 배포 중입니다. 에이전트 활동 관찰, 보안 방어 테스트, 위험 행동 탐지, 안전하지 않은 작업 차단의 4가지 기능을 제공하며, MLSys 2026에 논문이 수락되었습니다. 오픈소스 릴리스에는 ADR Sensor, ADR-Bench, ADR Detector가 포함되어 있고, 예방 기능은 향후 공개될 예정입니다.

obra/superpowers
266,199
Superpowers는 코딩 에이전트를 위한 소프트웨어 개발 방법론으로, 에이전트가 코드 작성 전에 먼저 요구사항을 파악하고 사용자와 함께 설계를 검증한 후 구현 계획을 수립한다. 계획 승인 후 subagent-driven-development 프로세스로 각 작업을 수행하며, TDD, YAGNI, DRY 원칙을 강조한다. 자동 트리거되는 스킬들로 구성되어 별도 설정 없이도 에이전트가 이 방법론을 적용할 수 있다.
