- Agent skill은 LLM 에이전트의 계획 수립, 도구 사용, 문제 해결, 검증 등 task 실행에 영향을 미치는 메커니즘
- 이전 연구에서 일부 스킬은 task 성공률을 향상시키지만, 다른 스킬들은 효과가 없거나 token 사용량과 실행 시간을 증가시키거나 성공률을 감소시킴

Switchyard는 Rust로 작성된 LLM 트래픽 프록시 라이브러리로, OpenAI와 Anthropic API 간 요청을 변환하고 다양한 백엔드로 라우팅한다.
- 프로토콜 변환: OpenAI Chat, Anthropic Messages, OpenAI Responses 형식 간 상호 변환
- 다중 백엔드 라우팅: 임의 라우팅, LLM 분류기 라우팅, 신호 기반 단계 라우터 등 여러 알고리즘 지원
- 운영 메트릭: Prometheus 메트릭으로 요청, 오류, 지연, 토큰, 라우팅 오버헤드 수집
