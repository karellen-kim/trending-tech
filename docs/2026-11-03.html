C++에서 = default와 {}로 정의한 생성자는 같지 않다
Daniel Lemire
C++에서 span() = default와 span() {}의 초기화 동작 차이와 성능에 미칠 수 있는 영향을 다룬 글이다.
- 첫 선언에서 = default로 정의한 기본 생성자는 span을 trivial 타입으로 만들지만, {}로 정의한 생성자는 사용자 제공 생성자이므로 span은 trivial 타입이 아니다.
- = default인 경우 span s;는 멤버를 초기화하지 않고, span s{}는 패딩까지 객체 전체를 0으로 초기화한다. {}인 경우 두 선언 모두 빈 생성자를 호출하며 멤버는 초기화하지 않는다.
- 예제의 box 기본 생성자는 내부 span을 값 초기화한다. 루프에서 i == n일 때 선택되는 box() 경로는 종료 시 한 번만 실행되며, 해당 span은 consume에 전달되지 않는다.
